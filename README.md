# Ontology of Ask

A single-page exploration of the Ontology of Ask: ten nodes, sixteen directed triples, read once as the shape of a question and once as the shape of a moment of experience.

`index.html` is self-contained (no build, no dependencies beyond Google Fonts). Open it in a browser, or serve it with GitHub Pages.

Sections: the directed graph with a node inspector, the sixteen triples as a ledger, the dual reading, six implications, and a working traversal in which an I casts Attention onto a Substrate, Ask surfaces trajectories to the depth Important allows, Choice collapses one, and the Answer is appended as a Node that later Asks traverse.

Two triples the prose asserts but the sixteen omit (Answer becomes Node; I comprises Answer) are off by default and drawn dashed when enabled. They are commentary, not canon.

*A rich I is one that asks.*
